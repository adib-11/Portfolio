BucketList is a SwiftUI app that lets users build a personalized map of places they want to remember or explore, combining a clean, privacy-conscious architecture with delightful, practical features. The app uses MapKit with an intuitive, tappable map to add locations, and displays custom annotations that can be long-pressed to edit details. A lightweight model layer persists data securely to disk using Codable and complete file protection, while Swift Concurrency powers seamless fetching of nearby points of interest from Wikipedia to enrich each place with contextual information. The experience is gated by secure biometric authentication via LocalAuthentication, ensuring personal data remains private. The codebase follows modern Swift practices—observable view models for state, clear separation of concerns, and dependency-light design—resulting in a fast, maintainable, and accessible app that feels at home across Apple platforms.
