SnowSeeker is a SwiftUI-based iOS app that helps users discover and explore ski resorts using a clean, adaptive master-detail interface powered by NavigationSplitView. It loads a bundled dataset from resorts.json, presents a browsable list with country flag thumbnails, resort names, and run counts, and offers fast, localized search via .searchable. Users can mark favorites, which are highlighted inline with a heart icon and shared across views through environment-injected state. The app leverages modern SwiftUI patterns including @State, environment models, and .navigationDestination for type-safe navigation, while incorporating accessibility labels for a more inclusive experience. Its modular structure and data-decoding approach provide a strong foundation for future enhancements like sorting, advanced filters, richer detail views, and cloud-synced favorites.
